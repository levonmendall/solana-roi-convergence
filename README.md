# Solana ROI Convergence

Paper-only research and execution simulator for **ROI Convergence v3.1** on Solana.

The project has one initial objective:

> Prospectively test whether a $500 paper account can compound profitably by combining historically predictive wallet first-touches, independent wallet convergence, strict token-risk vetoes, fast simulated execution, rapid failure exits, a +50% harvest, and an uncapped runner.

## Safety boundary

- Paper trading only.
- No private keys.
- No transaction signing.
- No live order submission.
- No custody, deposits, or withdrawals.
- Missing or stale required evidence fails closed.
- The baseline strategy is frozen during the initial forward certification cohort.

Implementation is being built on a dedicated branch before production data ingestion is enabled.
