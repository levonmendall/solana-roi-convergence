# Documentation archive

Files under `docs/archive/` are retained only for historical lineage, audit reconstruction and compatibility research. They are not current production authority.

Current production truth is defined by:

- `README.md`;
- `docs/ARCHITECTURE.md`;
- `docs/V51_CONSOLIDATED_STRATEGY.md`;
- `strategy_v51_authority.json`;
- the exact deployed `solana_roi.production:app` release;
- `/v1/system-proof` and `/readiness` for runtime proof/readiness.

Archived strategy documents must carry an explicit no-authority header. Git history remains the source for files that are deleted rather than retained.

## Archive layout

- `v3/` — superseded ROI Convergence v3.x strategy/baseline documents.
- `v4/` — superseded ROI Convergence v4.x strategy documents.

Do not link an archived document as if it describes current selection, sizing, promotion, exit, allocation, readiness or execution authority.
